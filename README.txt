Analog Lab 1.1 — слои и маски. Загрузите файлы в корень GitHub Pages с заменой старых. Слои обрабатываются снизу вверх, выбранный слой редактируется существующими регуляторами. Маска кистью рисуется на фотографии после выбора режима Кисть. Сохранить проект: JSON содержит слои и маски, но не исходное фото; откройте исходное фото отдельно. JPEG экспортируется до 4000 px. Слои могут замедлить обработку на телефонах.
