Analog Lab 1.0 — расширенная библиотека фотоматериалов.

Новые разделы: чёрно-белая, цветная, диапозитивная плёнка, архив фотоматериалов, аэро/инфракрасные интерпретации. Сохранены просроченные плёнки, Polaroid, альтернативная печать, BW_H и управление дефектами.

Установка: распакуйте ZIP, загрузите все 6 файлов в корень GitHub Pages репозитория с заменой существующих, затем Commit changes. Обновите страницу.

Важно: профили стилизованы, точное воспроизведение конкретных эмульсий и инфракрасного диапазона невозможно по обычному RGB-снимку.
