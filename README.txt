Analog Lab 0.3 — PWA

Разместите ВСЕ файлы из этой папки в корне репозитория GitHub Pages.
Settings → Pages → Deploy from a branch → main / (root).
Откройте опубликованный HTTPS-адрес в Chrome, меню ⋮ → Добавить на главный экран → Установить.
Для офлайн-работы сначала откройте опубликованный сайт с интернетом и дождитесь загрузки.
Открытие index.html локально не устанавливает PWA.
Фото обрабатываются в браузере и не отправляются на сервер.
